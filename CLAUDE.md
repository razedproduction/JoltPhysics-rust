# JoltPhysics-rust

Rust reimplementation of Jolt Physics. This repository is a fork of `jrouwe/JoltPhysics` (remote `upstream`): the C++
original stays untouched under `Jolt/`, `UnitTests/`, `PerformanceTest/`, ... and is the reference; the Rust port lives
in `crates/`. Do not modify upstream C++ files (keeps upstream merges conflict-free).

## Where things are

- `port/PORTING_PLAN.md` — contract, design decisions, slice order and status. Read it before starting a slice; update the
  status table when a slice lands.
- `port/DEVIATIONS.md` — every intentional behavior difference from C++, unported tests, bugs found in the original.
- `port/TEST_STATUS.md` — generated by `python tools/port/test_status.py`; regenerate after porting tests.
- Crates: `jolt-core` (Core + Math), `jolt-geometry` (Geometry, AABBTree, TriangleSplitter), `jolt-physics` (Physics,
  Skeleton, Renderer), `jolt` (facade), `jolt-test-utils` (port of `UnitTests/UnitTestFramework.h` and helpers).

## Porting rules

- Port semantics and keep the C++ algorithm and **floating-point evaluation order** exactly (bit-exact determinism with the
  C++ `CROSS_PLATFORM_DETERMINISTIC` build is a goal). Never use FMA, `std` trig/exp functions, `sort_unstable` or
  `HashMap` iteration where C++ uses its own implementation — port Jolt's.
- One Rust module per C++ header (`Jolt/Math/Vec3.h` + `.inl` -> `jolt_core::math::vec3`); keep the C++ doc comments.
- Naming: `GetX()` -> `x()`, `SetX()` -> `set_x()`, `sFoo()` -> `foo()`, enums drop `E` prefix; out-params become return values.
  Add non-obvious renames to the name table in the plan.
- Tests: a Rust file porting `UnitTests/X/Y.cpp` contains the marker `//! Port of UnitTests/X/Y.cpp`;
  `TEST_CASE("TestFooBar")` becomes `#[test] fn test_foo_bar()`. Port the tests of a slice before/with its code.
- `unsafe` only where unavoidable (SIMD, lock-free, job system), each block with `// SAFETY:`.
- Bugs in the original: port as-is, record in `port/DEVIATIONS.md`.
- Feature flags mirror CMake: `double-precision`, `cross-platform-deterministic`, `debug-renderer`, `profiler`.

## Commands

```bash
cargo fmt --all
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace
cargo test --workspace --features jolt/double-precision
python tools/port/test_status.py
```

C++ original (oracle): build tools are in `D:\Programs\VSC18` (VS 2026, MSVC 14.50, not on PATH). Run
`D:\Programs\VSC18\VC\Auxiliary\Build\vcvars64.bat` first (CMake/Ninja: `Common7\IDE\CommonExtensions\Microsoft\CMake`),
then `Build\cmake_vs2026_cl_cross_platform_deterministic.bat`.
